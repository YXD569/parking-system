# 🚀 智慧停车 BI 数据分析与管理系统 (Parking BI System)

基于 `uni-app` + `Vue3` 开发的跨平台（H5 / 微信小程序 / App）智慧停车管理与数据分析系统。

本项目不仅实现了完整的**车辆进出场业务闭环**与**自动计费引擎**，更在此基础上构建了**前端轻量级 BI 数据仓库**，实现了从数据采集、ETL 清洗、多维分析（RFM模型/环比分析）到可视化大屏展示的全链路数据驱动闭环。

---

## ✨ 核心功能矩阵

### 🚗 基础业务模块 (Business)
*   **入场登记**：支持车牌识别模拟、车位自动分配、重复入场拦截与满员预警。
*   **出场计费**：基于分时段规则（白天/夜间/封顶）的自动计费引擎，支持模拟在线支付。
*   **车位监控**：实时车位状态网格图与使用率监控。
*   **车辆管理**：车辆档案的增删改查，区分临时车与月租车。
*   **规则配置**：动态配置免费时长、计费费率与封顶金额。

### 📊 数据分析模块 (BI & Analytics)
*   **专业数据看板**：引入 `uCharts` 引擎，渲染近 7 天营收趋势图、24 小时车流分布图。
*   **核心业务指标**：自动计算并展示**车位周转率**、**平均客单价 (ARPU)**、**平均停车时长 (ATL)**。
*   **环比/同向分析**：实时对比今日与昨日营收，自动计算并展示环比增幅/降幅。
*   **RFM 用户价值分层**：基于历史流水，运用 RFM 模型对车辆进行画像分层（如：重要价值客户、高频低价值客户）。
*   **动态规则预警**：内置规则引擎，自动监测“车位过载 (>85%)”、“营收异常下跌”以及“僵尸车 (停留>48h)”并生成业务预警。
*   **多维复合查询与 ETL 导出**：支持时间范围、支付状态、车牌模糊组合查询。纯前端实现 CSV 报表生成（处理了中文 BOM 头防乱码），支持一键下载离线分析。
*   **脏数据清洗**：支持一键识别并清理长期未出场的异常测试数据。

## 🧠 核心数据模型与算法说明

### 1. 计费引擎算法
系统采用**分时段步长计费**与**每 24 小时封顶**策略。
*   逻辑：过滤免费时长后，以 30 分钟为步长切片，判断切片所处时间段（白天 8:00-20:00 / 夜间 20:00-8:00），累加对应费率。最后校验封顶金额。

### 2. RFM 用户分层模型
数据层对已支付的订单按 `plateNumber` 进行 `GroupBy` 聚合：
*   **R (Recency)**：最近一次消费时间。
*   **F (Frequency)**：累计入场频次。
*   **M (Monetary)**：累计消费金额。
*   *当前策略*：累计金额 ≥ 20元 且 消费频次 ≥ 2次 判定为【重要价值客户】；频次 ≥ 3次 但金额 < 20元 判定为【高频低价值客户】。

### 3. 前端 ETL (数据清洗与导出)
*   **数据清洗**：遍历当前在场车辆，若 `当前时间 - 入场时间 > 7天`，则判定为脏数据/僵尸车，前端直接标记出场并拦截异常计费。
*   **CSV 导出**：手工拼接 CSV 格式字符串，使用 `new Blob(['\uFEFF' + csvContent])` 增加 BOM 头，完美解决 Excel 打开时中文乱码的问题，并利用原生 DOM 创建 `<a>` 标签触发下载。
